# Plano de verificação do DVC

1. Configurar o download autenticado no workflow e documentar a configuração local no README.
2. Exercitar o fluxo com arquivos sintéticos em um remote local e um segundo clone. Confirmar que a verificação detecta divergência nos agregados.
3. Confirmar a URL do DagsHub e enviar os objetos existentes que correspondem aos ponteiros Git.
4. Rodar o pull dos dois ponteiros num clone limpo e verificar o workflow depois da configuração dos Secrets.
