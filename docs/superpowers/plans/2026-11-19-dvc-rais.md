# Plano de configuração do DVC para a RAIS

1. Configurar o remote S3 padrão do DagsHub sem credenciais em `.dvc/config`.
2. Incluir o suporte S3 nas dependências do DVC e atualizar o lockfile.
3. Adaptar o workflow de verificação do PR #38 para autenticação S3 via Secrets e manter a documentação atual do README.
4. Validar configuração, dependências e workflow localmente.
5. Com credenciais de leitura, baixar os dois objetos em clone limpo, conferir os hashes, regenerar agregados e verificar que `data/agregados/` não tem alterações.
